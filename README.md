# Clash of Schmels

Изометрическая 2D-фабрика пчёл на **Phaser 3 + TypeScript**. Начните с бесплатного роя, выращивайте специалистов, стройте цепочки производства и развивайтесь от ручной мастерской до электрических центрифуг.

Phaser управляет всем игровым миром: WebGL/Canvas, камерой, выбором объектов, глубиной отрисовки, спрайтовыми анимациями, полётами, грузами, рубкой, маршрутами и строительным предпросмотром. React отвечает за доступный HTML-интерфейс поверх игры: меню, обучение, рецепты и полосы ресурсов. Next.js запускает клиент и API. Прежнего SVG-рендера карты здесь нет.

## Запуск

Нужны Node.js 22+ и pnpm 9.

```sh
pnpm install
pnpm dev
```

Откройте http://127.0.0.1:3100/bee. Галерея графики: http://127.0.0.1:3100/bee/assets/index.html.

```sh
pnpm test       # симуляция, карты, логистика, координаты, сохранения и повторы операций
pnpm typecheck
pnpm build
pnpm start      # production-сборка на том же порту 3100
pnpm simulate   # контрольный путь развития без выдачи ресурсов
```

## Что уже работает

- 21 постройка, четыре эпохи, девять ресурсов и четыре профессии пчёл.
- Локальные запасы в зданиях, реальные полёты с грузом и нехватка работников.
- Всплывающие уведомления над зданиями показывают производство, доставку и переход склада в пустое или заполненное состояние.
- Воздушные маршруты, конвейеры, валы, трубы и электрические сети с перегрузкой.
- Случайная сохраняемая долина, гарантированная река, лес, руда и расширение тумана войны.
- Камера: перетаскивание, колесо мыши, кнопки масштаба, pinch жест двумя пальцами; стрелки двигают камеру или строительный предпросмотр.
- Рубка: полёт к дереву, работа топором, падение, обратный полёт и доставка древесины.
- Короткое обучение, информация о зданиях, готовность следующей эпохи, серверные таймеры.
- Офлайн-производство до восьми часов; поздние эпохи рассчитаны на несколько дней.

## Своя графика

Всё лежит в [`public/bee/assets/`](public/bee/assets/README.md). Измените файл или запись `manifest.json`, увеличьте `version` и обновите страницу. Пересборка для замены публичных файлов не нужна. PNG/WebP/SVG поддерживаются; для собственной покадровой анимации предусмотрено поле `sheet`. Существующие SVG-анимации подготовляются в текстурные кадры при загрузке, затем проигрываются Phaser. Подробности, размеры, точки опоры и контуры выбора — в README ассетов.

## Сохранения и два режима API

**Самостоятельный локальный режим** включён по умолчанию. Node-сервер считает симуляцию и хранит колонии в `data/colonies.json`. HttpOnly cookie выбирает колонию браузера. У каждого браузера отдельная пасека. Запись атомарная, операции выполняются последовательно, ключи повторных запросов сохраняются на диск. Перезапуск сохраняет карту и прогресс. Скопируйте папку `data/` для резервной копии; не публикуйте её. Этот режим рассчитан на один серверный процесс и локальную игру. Денежные выплаты выключены.

**Интеграция Bitter**: задайте `BITTER_API_ORIGIN` в `.env.local`. Маршруты `/api/bee`, `/api/bee/action`, `/api/bee/heartbeat` будут проксироваться на существующий сервер Bitter, вместе с сессионными cookie. Тогда используются сохранения, авторизация и денежный фонд Bitter. Клиент не получает права начислять реальные деньги. Размещайте клиент под тем же доверенным origin, что и вход в Bitter, либо настройте общий gateway; при переносе на другой домен cookie не появляются автоматически. Origin клиента должен быть разрешён сервером Bitter. `NEXT_PUBLIC_BITTER_WEB_URL` задаёт ссылку возврата на сайт.

Текущая пасека из Bitter не включена в Git и не копируется в гостевой локальный режим. Она остаётся в базе Bitter и доступна через его API. См. [контракт интеграции](docs/bitter-api.md).

## Структура

```text
src/app/bee/phaser/ColonyScene.ts   сцена Phaser, ввод, камера и визуальные объекты
src/app/bee/phaser/model.ts         изометрические координаты и траектории
src/app/bee/Valley.tsx              жизненный цикл Phaser внутри React
src/app/bee/page.tsx                HUD, строительство, управление производством
src/game/bee-game.ts                общая детерминированная симуляция
src/game/bee-legacy.ts              миграция прежних сохранений
src/server/                        локальное хранилище и проверка команд
src/app/api/bee/                    локальный API / proxy Bitter
public/bee/assets/                  заменяемые спрайты, иконки и текстуры
```

Симуляция намеренно независима от Phaser: сервер проверяет действия, браузер показывает краткий прогноз и синхронизируется с сервером. Перенос в движок не меняет рецепты, темп развития и денежные правила.

Графика и её происхождение: [CREDITS](public/bee/assets/CREDITS.md). Зависимости сохраняют собственные лицензии; сторонние игровые ассеты Supercell/Factorio/Create не включены.
