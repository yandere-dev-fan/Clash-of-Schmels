# Ассеты Clash of Schmels

**Это рабочая папка игры.** Все изображения читаются отсюда; спрайты больше не нарисованы внутри React-компонентов.

Открыть визуальный каталог: http://127.0.0.1:3100/bee/assets/index.html

## Как заменить рисунок

1. Найдите файл в папке ниже и замените своим с тем же именем. Обновите страницу игры.
2. Если у нового файла другой формат или имя, измените `src` у нужного ключа в `manifest.json`. Поддерживаются SVG, PNG и WebP. Для покадровой анимации в Phaser используйте спрайт-лист (`sheet`, пример ниже). Анимированные GIF/WebP в WebGL не воспроизводятся покадрово автоматически.
3. Для замены анимации измените **также `activeSrc`**. Если анимации пока нет, удалите `activeSrc` — работающая постройка будет использовать ваш обычный `src`, а не старый рисунок.
4. Увеличьте `version` в manifest (например, 1 → 2), если браузер держит старое изображение в кэше.

**Пересборка приложения не нужна** для замены файлов и правки manifest в этой папке. Он загружается при открытии игры. После публикации нужно доставить изменённые файлы на сервер; локальная замена сама по себе не обновляет продакшен.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `buildings/` | 21 вид здания. `hive.svg` — улей; `wild.svg` — маточный; `depot.svg` — хранилище; `workshop.svg` — мастерская; `nursery.svg` — расплодник. Файлы `*-active.svg` — работающая версия. |
| `bees/` | `forager` собиратель, `carrier` грузчик, `engineer` механик, `forester` лесник, `builder` строитель. `*-flight.svg` — полёт. |
| `icons/` | Все значки интерфейса и ресурсов: honey, wax, wood, planks, gears, water, nectar, ore, copper и кнопки. |
| `terrain/` | Три варианта травы, вода, дерево, камень, пень, дикие цветы, дальний лес, закрытая земля и туман войны. |
| `cargo/` | Переносимые пчёлами/конвейерами грузы каждого ресурса. |
| `routes/` | Текстуры конвейеров, валов, кабелей, труб и воздушных маршрутов. |
| `effects/` | Топор, щепки, строительные леса и заглушка для отсутствующего изображения. |

Полосы прогресса, рамки выбора, контуры трасс, сетка и расположение кнопок остаются геометрией интерфейса, а не картинками. Менять их для подстановки своих текстур не требуется. Свойства визуального масштаба и точек опоры задаются в manifest.

## Размеры и точка опоры

- Здания: исходный холст **160×150**, точка касания земли **80,126**. Сохраняйте прозрачный фон. Все площадки имеют одинаковый масштаб; перенесите выступающие тени внутрь холста.
- Дерево: **160×180**, точка основания ствола **80,146**.
- Пчёлы: **36×32**, центр тела **17,16**. Груз рисуется отдельно под телом.
- Иконки: **24×24**; одинаковые поля по краям помогают читаемости.
- Изометрическая клетка: **76×44**; вершины ромба (38,0), (76,22), (38,44), (0,22). Земля и вода должны сходиться по краям.

Можно использовать другие разрешения: задайте реальные `width`, `height` и `anchor` в manifest. `anchor` — точка основания в координатах исходного холста. Игра масштабирует изображение и ставит эту точку на землю. Например:

```json
"building.hive": {
  "src": "buildings/my-hive.png",
  "activeSrc": "buildings/my-hive-working.webp",
  "width": 320,
  "height": 300,
  "anchor": { "x": 160, "y": 252 }
}
```

## Чтобы по дереву было удобно попадать

`terrain.tree.hitArea` задаёт **контур выбора**, а не прямоугольник всей PNG. Каждая точка `[x,y]` задаётся относительно точки опоры в долях отображаемой ширины. `[-0.4,-0.7]` означает 40% ширины влево и 70% ширины вверх от основания. Обведите видимую крону и ствол, не прозрачные углы. При наведении или выборе игра подсветит именно этот объект. Здания тоже поддерживают `hitArea`; по умолчанию используется компактный контур вокруг корпуса.

## Анимации

Ресурсы перемещаются по реальным серверным заданиям. Позицию пчелы и груз управляет игра; менять их в SVG не нужно. Внутри `*-active.svg` можно менять движение крыльев, шестерёнок, поршней и дыма. Рабочее состояние подставляется автоматически; для остановленной машины используется обычный файл.

Рубка состоит из прилёта, десяти секунд работы и обратного полёта. Если есть свободный лесник, полетит он; на старте эту работу выполняет строитель, чтобы игрок без древесины не застрял. Дерево падает при окончании рубки, а древесина поступает после возврата. Лесная станция использует постоянных лесников и рубит дерево частями.

SVG не должны включать внешние шрифты, скрипты или ссылки на чужие изображения: сохраняйте их самодостаточными. При ошибке загрузки игра покажет `effects/missing.svg`.


## Анимации в Phaser

Карта теперь рисуется в Phaser / WebGL. Существующие SVG с классами `gear`, `wheel`, `piston`, `pumpArm`, `steam`, `breathe`, `wing`/`wings`, `beltMotion`, `hiveGlow`, `flowerSway` преобразуются в 12 поз и проигрываются движком. Произвольные CSS keyframes внутри вашего SVG движок не интерпретирует. Для собственных анимаций задайте спрайт-лист одинаковых кадров слева направо, затем сверху вниз:

```json
"building.hive": {
  "src": "buildings/my-hive.png",
  "width": 160,
  "height": 150,
  "anchor": { "x": 80, "y": 126 },
  "sheet": {
    "src": "buildings/my-hive-sheet.png",
    "frameWidth": 160,
    "frameHeight": 150,
    "endFrame": 7,
    "frameRate": 12
  }
}
```

`endFrame` — индекс последнего кадра с нуля. В этом примере восемь кадров. `sheet` имеет приоритет над `activeSrc`; `src` остаётся видом остановленной постройки. Все кадры должны иметь одинаковую точку опоры. Режим уменьшенного движения отключает декоративное проигрывание, сохраняя реальные перемещения грузов.
